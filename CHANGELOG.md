# Changelog

All notable changes to this project are documented in this file.

## [0.4.0] - 2026-11-26

### Bug Fixes
- Name the command and the tab as they stand now

### Features
- Build a short under the look kilna keeps for its channel

### Breaking Changes
- Needs kilna 0.168 or later. The blur-and-bars layout and
its settings (channel, call, hand, ink, bar_shade, fonts, cover_seconds) are
gone; what a short looks like is set in kilna.
